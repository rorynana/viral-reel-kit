# 내 채널용 바이럴 릴스 한 편 만들기

사용자는 개발자가 아니다. 명령은 네가 직접 실행하고, 사용자에게는 결과와 고를 것만 짧게 보여 준다.
명령은 전부 키트 폴더(이 파일의 세 단계 위)에서 `python tools/...` 로 실행한다. `python` 이 없으면 `py` 로, 둘 다 없으면 파이썬부터 설치한다(윈도우: `winget install -e --id Python.Python.3.12`, 설치 뒤 터미널 새로 열기).
PowerShell에서 명령은 한 번에 하나씩 실행한다(`;` 로 여러 명령을 잇지 않는다).
이 키트는 어떤 서버나 계정에도 접속하지 않는다. 소재는 `seeds/` 에 이미 들어 있다.
실습 시간이 30분이다. 묻는 것은 아래 「사람이 정하는 것」 넷뿐이고, 나머지는 네가 정해서 바로 진행한다.

## 사람이 정하는 것 (이것만 묻는다)

1. 내 채널 정보(0단계): 채널 이름, 인스타 핸들, 대표 색, 이 채널에서 보여 줄 것 세 가지
2. 소재 묶음(1단계): AI 영상 / 뷰티 브랜드 / 생활·라이프 중 하나, 또는 직접 고른 후보 번호
3. 카피 OK(4단계): 장별 헤드·본문 표를 보여 주고 OK 받기
4. 완성본 확인(6단계): 릴스.mp4 와 전체그리드.png 경로를 주고 직접 열어 보게 하기

## 0. 준비 ("설치해줘", "준비됐어?", 첫 대화면 여기부터)

1. `python tools/check.py` 를 실행한다.
2. 부품이 없으면 `python -m pip install -r requirements.txt`, ffmpeg 가 없으면 `winget install --id Gyan.FFmpeg -e --accept-source-agreements --accept-package-agreements`. ffmpeg 설치 뒤에는 이 터미널에서 바로 안 잡힐 수 있으니, 설치 경로(보통 `%LOCALAPPDATA%\Microsoft\WinGet\Packages` 아래 `ffmpeg.exe`)를 찾아 PATH 에 붙여서 쓴다. 맥은 `brew install ffmpeg`.
3. 내 테마가 없으면 사용자에게 한 번에 묻는다: 「채널 이름, 인스타 핸들, 대표 색(예: 파랑), 이 채널에서 보여 줄 것 세 가지를 알려 주세요」. 답을 받으면
   `python tools/theme.py --name "<채널 이름>" --handle "<핸들>" --color "<#색>" --head "<두 줄 질문, / 로 줄바꿈>" --sub "<한 줄 소개>" --items "<a|b|c>" --hashtag "#<채널태그>"`
   색은 말로 받으면 네가 #코드로 바꾼다. head·sub 는 사용자 답으로 네가 쓴다.
4. check.py 를 다시 돌려 전부 OK 면 1단계로.

## 흐름 (순서 지키기)

1. **소재 고르기**: `python tools/find.py --kit` → 묶음 세 개를 한 줄씩 요약해 보여 주고(묶음마다 가장 크게 터진 영상 하나와 배수) 사용자가 고르게 한다. 전체 후보가 보고 싶다고 하면 `python tools/find.py`.
2. **원본 준비**: 에피소드 이름을 정한다(한글 OK, 예: `AI영상편`). 고른 묶음의 영상 4~6개 링크를 넣는다.
   `python tools/fetch.py <에피소드> <링크1> <링크2> ...` (키트에 든 영상은 복사만 하므로 몇 초면 끝난다)
3. **구간 보기**: `python tools/sheet.py <에피소드>` → `episodes/<에피소드>/sheets/*.jpg` 를 직접 열어 보고 장마다 쓸 구간(시작 초, 길이)을 정한다.
   **구간은 "그 영상이 왜 터졌는지 보여 주는 장면(beat)"부터 정한다.** 움직임이 큰 곳을 먼저 고르지 않는다.
   반전·대사형은 앞 상황(셋업)부터 넣는다. 키트 영상은 앞 30초까지만 들어 있다.
4. **카피 쓰기**: 아래 "spec.json 형식"대로 `episodes/<에피소드>/spec.json` 과 `캡션.txt` 를 쓴다.
   구성은 표지 1 + 사례 4 + 결론 1 + CTA 1 = 7장으로 한다(시간 때문에).
   영상 설명과 `clips/_sources.json`(계정·조회·평소 대비·날짜)만 근거로 쓴다. 없는 숫자를 지어내지 않는다.
   결론 장은 「이 묶음에서 보이는 공통점 한 줄」이다. 내 채널이 무엇을 보는 채널인지(테마의 items)와 이어지게 쓴다.
   사례 장마다 `beats` 를 적는다. 다 쓰면 장별 헤드·본문과 beat(몇 초에 무엇이 보이는지)를 표로 보여 주고 OK를 받는다.
5. **검사**: `python tools/lint.py <에피소드>` → FAIL이 0이 될 때까지 카피를 고친다(사용자에게 묻지 않고 네가 고친다).
6. **만들기**: `python tools/build.py <에피소드>` → `전체그리드.png` 를 직접 열어 글자 잘림·겹침이 없는지 본다.
   이어서 `검수/<장>.jpg` 를 전부 열어 빨간 테두리 칸마다 beat의 what이 실제로 보이는지 본다. 아니면 고치고 `--only <장이름>` 으로 다시 만든다.
   다 확인한 뒤 사용자에게 `릴스.mp4`, `전체그리드.png`, `캡션.txt` 의 전체 경로를 준다.
7. **올리기는 사람이 한다**: 이 키트에는 자동 발행이 없다. 「인스타 앱에서 릴스.mp4 를 올리고 캡션.txt 를 붙여 넣으면 됩니다. 남의 영상을 쓴 것이라 출처 표기는 지우지 마세요」라고 안내하고 끝낸다.

## 카피 기본 규칙 (어기면 lint가 막거나 반려된다)

- em-dash(—) 금지. 쉼표·줄바꿈·콜론으로.
- 표지 헤드는 **3줄 고정**. 2줄·4줄 금지.
- 표지 장면은 사례 장에 다시 나오지 않는 장면으로 고른다(lint가 같은 원본·겹치는 구간을 막는다). 같은 영상의 다른 장면이나 다른 영상에서 가져온다.
- 캡션 해시태그는 **3개**: 내 채널 태그(themes/mine/theme.json 의 cta.hashtag) + 주제 2개.
- 사례 장 하단 foot에 **출처**(원작 계정 · 플랫폼 조회 · 날짜 기준)를 꼭 적는다. 조회수는 `_sources.json` 값.
- 도구·모델 이름은 뭉개지 말고 그대로(예: "AI로" 말고 "PixVerse로").

## spec.json 형식

장은 최대 10장. 첫 장은 반드시 표지(cover), 끝 장은 CTA. 보통 표지 1 + 사례 4~6 + 결론 1 + CTA 1.
`src` 는 에피소드 폴더 기준 경로(`clips/<영상id>.mp4`). `ss` = 시작 초, `t` = 길이(3~20초, 권장 6~12초).
글자 강조: 표지·결론의 `lines` 는 줄마다 `[["글자", 0], ["강조할 글자", 1]]` (1이 주황 강조).

```json
{
  "slides": [
    {"name": "01_표지", "kind": "cover", "src": "clips/Ddg3aRwJ_QX.mp4", "ss": 1.2, "t": 3.0, "fx": 0.5,
     "badge": "AI 트렌드",
     "lines": [[["80살 스탤론이", 0]], [["후버댐에서 뛰어내림", 0]], [["근데 PixVerse임", 1]]],
     "sub": "9일 만에 릴스 6편으로 3,400만 뷰 찍은 할아버지"},
    {"name": "02_사례1", "kind": "full", "src": "clips/DdzsuoWonQN.mp4", "ss": 2.0, "t": 6.0,
     "pill": "사례 1",
     "head": "올린 지 하루 만에 685만, 이게 되네",
     "body": "오토바이째 옥상에서 뛰어내렸다가 다시 올라옴.\n물리법칙은 이 영상에서 퇴근함.",
     "foot": "@georgewuai · 인스타 릴스 조회 685.8만 · 9/29 기준",
     "beats": [{"at": 3.5, "what": "오토바이째 옥상에서 뛰어내림"}, {"at": 6.0, "what": "다시 올라옴"}]},
    {"name": "07_결론", "kind": "statement", "dark": true,
     "lines": [[["가짜인 거 알아도", 0]], [["끝까지 보게 하면", 0]], [["그게 ", 0], ["바이럴", 1], ["입니다", 0]]],
     "sub": "한 줄 근거(댓글·숫자)"},
    {"name": "08_CTA", "kind": "cta"}
  ]
}
```

- `kind`: `cover`(표지) / `full`(세로 영상을 4:5로 채움, 대부분 이것) / `win43`(가로·4:3 영상을 위에 창으로) / `statement`(결론 글자 장) / `cta`(내 채널 소개, 내용은 내 테마에서 자동)
- `name` 은 `01_`, `02_` 처럼 두 자리 번호로 시작.
- 가로 영상(16:9 등)은 `win43` 을 쓴다. `full` 로 쓰면 가운데만 잘린다.
- 사례 장 `body` 는 두 줄까지(줄바꿈 `\n` 하나).
- 사례 장 `beats` 필수. `at` 은 원본 기준 초. 각 beat는 `ss+0.3` 이후, `ss+t-2` 이전에 있어야 한다(끝나기 2초 전엔 이미 보여야 함).
- 사례 장 `t` 는 카피 읽는 시간 이상: (헤드+본문 글자 수, 공백 제외) ÷ 9 + 1.5초, 최소 6초. 모자라면 구간을 늘리거나 카피를 줄인다.

완성본 spec 예시는 `episodes/예시_spec.json`.
